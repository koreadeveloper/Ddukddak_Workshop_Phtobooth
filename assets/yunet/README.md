# YuNet face detection models

Bundled OpenCV Zoo weights for offline face and landmark detection. OpenCV 4.5–4.7 uses the 2022 export and OpenCV 4.8+ uses the 2023 export. The model detects face bounds and landmarks only. The project does not match faces to identities with it.
